## 缺陷、已确认变更、待确认事项

### 已修复缺陷（非规格变更）

第一次真实生产探针已通过配置恢复、角色/发现与父 manager reload 重连，之后遇到 test-only `send-keys` pane target 格式错误；修正探针 target 为 `=session:0.0`（生产 switch-client 使用 session target，不受影响）。下一次在真实子 `/reload` 已成功后，正常停止遇到：

```text
EACCES: permission denied, open '/proc/<test-Pi-PID>/environ'
```

退出期间 `/proc` 可在已读到 cmdline 后变得不可读，原驱动在检查 zombie 前并行读 environ/stat，因此把退出瞬态当成无法确认身份的活进程。

修复：先读 stat 排除 zombie；读取权限错误时再查 stat，**只有明确 zombie 或进程已消失才忽略**。无法读取身份但仍活着/状态无法确认的候选仍抛原错误，绝不放宽归属校验、杀不明进程或把清理失败当成功。新增确定性回归；最终真实生产探针连续 3 次通过（修复后的首次单次也通过）。

### 已确认变更（沿用前序）

任务 01 用户接受的 `sendUserMessage(): void` 调用发起确认继续有效：`✓ Delivered` 不保证接受/排队/落盘/完成；create 仍必须另验初始可恢复文件。没有新增确认、重投、metadata 或改动规格。

### 待确认/剩余事项

没有发现新的需调整产品规格的事项；没有静默修改 spec 来迁就实现。仍需决定如何执行**真实模型及人工终端验收**，这些是验证缺口，不是默认已通过；涉及费用/用户终端接管须先获得同意。
