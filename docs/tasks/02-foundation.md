# 02 — 基础模型、路径与测试基础

## 依赖与阅读

- 依赖 01，阅读其交接及 implementation-notes。
- spec：第 3、5、6、7、11 节，工具参数表。
- package.json、tsconfig.json、入口文件和现有测试。

## 目标与范围

建立后续模块共同使用的轻量基础，不启动 tmux、不实现 socket 或工具业务。

## 工作

1. 建立最小可用测试运行方式，优先简单方案；确保 typecheck 能执行。
2. 提供合法的默认扩展工厂入口，暂不注册未实现能力。
3. 定义四种操作的内部类型、working/idle，以及与工作状态区分的不可用/连接错误信息。
4. 确定 name 的校验与安全目录映射规则。同父会话唯一、不另生成业务 ID，避免路径穿越与编码碰撞。
5. 实现 agent-dir、父会话/子代理目录、session.jsonl 路径和扫描逻辑。
6. 规范化运行目录绝对路径，计算 SHA-256 前 32 个十六进制字符的 socket 地址；处理有效 XDG_RUNTIME_DIR 与 /tmp/pi-subagent-uid 回退，限制运行时目录访问权限。
7. 检查 socket 路径字节长度，处理不安全目录等错误，不写 metadata 或运行状态。

## 验收

- 测试覆盖中文和特殊名称、路径穿越、目录映射唯一性、不同父会话隔离、哈希稳定性、运行时目录回退和路径长度。
- 目录扫描只识别本扩展应管理的目录，不能误删任何数据。
- typecheck 和新增测试通过。
- 在交接中固定路径和名称 API，供 03/05 使用。

## 非目标

协议、进程管理、模型调用、UI、工具 schema 和渲染。
